# พัฒนาเว็บผ่าน Claude (อัตโนมัติ)

```
คุณบอก Claude ว่าอยากได้อะไร
 → Claude อ่านโค้ดเดิม แก้/ออกแบบ แล้วทดสอบเอง (ทุกหน้า ทุกบทบาท มือถือ/แท็บเล็ต/คอม สิทธิ์ฐานข้อมูล)
 → Claude ส่งขึ้น GitHub
 → GitHub Actions ทดสอบซ้ำ → รวมเข้า main → อัปเดตฐานข้อมูล (ถ้ามี · สำรองก่อน) → ขึ้นเว็บ → ตรวจว่าเว็บจริงเป็นรุ่นใหม่
 → Claude สรุปผลให้คุณ
```
ถ้าขั้นใดไม่ผ่าน ระบบจะหยุด และเว็บจริงยังเป็นรุ่นเดิม Claude จะอ่านสาเหตุแล้วแก้เอง

## ตั้งค่าครั้งเดียว
1. **Secrets:** ตั้งตาม [BACKUP.md](BACKUP.md) ถ้ายังไม่ได้ทำ ระบบใช้ secrets ชุดเดียวกันทั้งสำรองข้อมูลและอัปเดตฐานข้อมูล
2. **GitHub → Settings → Pages → Build and deployment → Source:** เลือก **GitHub Actions**
3. **อัปโหลดชุดนี้เป็นครั้งสุดท้าย**
   - แตก zip แล้วลาก *ทุกอย่างในโฟลเดอร์ `pharmacy`* ไปวางทับใน GitHub แล้วกด Commit
   - ตรวจว่าโฟลเดอร์ `.github` และ `.claude` ขึ้นไปด้วย
   - แท็บ **Actions** → งาน **ci-deploy** ต้องขึ้นเครื่องหมายถูกสีเขียว (ใช้เวลาประมาณ 5–8 นาที)
4. **เชื่อม Claude กับ repo:**
   - เปิด **claude.ai/code** → เชื่อม GitHub → ติดตั้ง **Claude GitHub App**
   - เลือก *Only select repositories* → `pharmacy`

## ใช้งานทุกวัน
เปิด claude.ai/code (บนมือถือก็ได้) → เลือก repo **pharmacy** → พิมพ์สิ่งที่ต้องการ เช่น
- "เปลี่ยนสีหลักของเว็บเป็นเขียวโรงพยาบาล"
- "เพิ่มหน้าตารางนัดเยี่ยมบ้านของแต่ละ รพ.สต."
- "ปุ่มบันทึกในหน้าเยี่ยมบ้านบนมือถือกดยาก ช่วยแก้"

งานแรกที่แนะนำ: พิมพ์ว่า **"ทำงานค้างใน CLAUDE.md"** ให้ Claude ลบไฟล์ซ้ำที่หลุดอยู่หน้าแรกของ repo

## สิ่งที่ยังต้องทำเอง (นาน ๆ ครั้ง)
- **ตั้งค่านอก GitHub:** Supabase Dashboard เช่น Google login หรือ URL หรือ Google Cloud Console โดย Claude จะบอกขั้นตอนสั้น ๆ ให้
- **ยืนยันในแชท:** เมื่อ Claude ถามก่อนลบข้อมูลในฐานข้อมูล
- **ตรวจงาน:** ดูผลบนเว็บว่าตรงกับที่ต้องการไหม

## ความปลอดภัย
- รหัสลับทั้งหมดอยู่ใน GitHub Secrets เท่านั้น
- Claude ไม่เห็นรหัสลับ และไม่ต้องใช้
- ห้ามส่งรหัสลับในแชท
- ระบบตรวจทุกครั้งว่าไม่มีรหัสลับหลุดเข้าไปในโค้ด ถ้าพบจะไม่ขึ้นเว็บ
