# Primary Care Pharmacy Services

เว็บงานเภสัชกรรมปฐมภูมิ **โรงพยาบาลควนกาหลง จังหวัดสตูล** และ รพ.สต. ในอำเภอควนกาหลง

🌐 https://piyavutkkl-ch.github.io/pharmacy/

## ใช้อะไรบ้าง (ฟรีทั้งหมด)
| ส่วน | บริการ |
|---|---|
| หน้าเว็บ | GitHub Pages |
| เข้าสู่ระบบ | Google (ผ่าน Supabase Auth) |
| ฐานข้อมูล + ไฟล์ | Supabase Free (สิงคโปร์) |
| สำรองข้อมูล + กันระบบหลับ | GitHub Actions → Google Drive กลาง |

## สิทธิ์ผู้ใช้
- **ประชาชนทั่วไป** — ใครก็ได้ที่ login ด้วย Google
- **เจ้าหน้าที่ รพ.สต. / ผู้ดูแล** — ผู้ดูแลเพิ่มอีเมลที่ เมนูผู้ดูแลระบบ → บัญชีเจ้าหน้าที่ (มีผลทันทีที่คนนั้น login)

## แก้ไขเว็บ
- สั่งงานผ่าน Claude (claude.ai/code) → Claude แก้ ทดสอบ แล้วส่งขึ้น GitHub → ระบบทดสอบซ้ำ อัปเดตฐานข้อมูล และขึ้นเว็บเอง — ดู [docs/WORKFLOW.md](docs/WORKFLOW.md)
- กติกาสำหรับ AI อยู่ใน `CLAUDE.md` · ทดสอบทั้งหมด: `bash tests/run_all.sh`

## สำรองข้อมูล
- ทุกสัปดาห์ ระบบสำรองฐานข้อมูลและไฟล์ (เข้ารหัส) ไป Google Drive กลางอัตโนมัติ และกัน Supabase หยุดโปรเจกต์
- วิธีตั้งค่าและวิธีกู้ข้อมูล: [docs/BACKUP.md](docs/BACKUP.md)
