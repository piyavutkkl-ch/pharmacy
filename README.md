# Primary Care Pharmacy Services

เว็บงานเภสัชกรรมปฐมภูมิ **โรงพยาบาลควนกาหลง จังหวัดสตูล** และ รพ.สต. ในอำเภอควนกาหลง

🌐 https://piyavutkkl-ch.github.io/pharmacy/

## ใช้อะไรบ้าง (ฟรีทั้งหมด)
| ส่วน | บริการ |
|---|---|
| หน้าเว็บ | GitHub Pages |
| เข้าสู่ระบบ | Google (ผ่าน Supabase Auth) |
| ฐานข้อมูล + ไฟล์ | Supabase Free (สิงคโปร์) |

## สิทธิ์ผู้ใช้
- **ประชาชนทั่วไป** — ใครก็ได้ที่ login ด้วย Google
- **เจ้าหน้าที่ รพ.สต. / ผู้ดูแล** — ผู้ดูแลเพิ่มอีเมลที่ เมนูผู้ดูแลระบบ → บัญชีเจ้าหน้าที่ (มีผลทันทีที่คนนั้น login)

## แก้ไขเว็บ
- แก้ไฟล์ใน repo นี้แล้ว commit ที่ branch `main` → เว็บอัปเดตใน 1–2 นาที
- ใช้ AI (Claude) ช่วยพัฒนาได้: ให้ Claude อ่าน `CLAUDE.md` ก่อนเสมอ
- ฐานข้อมูล: ไฟล์ SQL ใน `supabase/` รันใน Supabase → SQL Editor ตามลำดับเลข
